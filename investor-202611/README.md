# HogentX 投资人进展汇报（2026 年 11 月）

给现有投资人的进展汇报，中文，17 页正文加 3 页附录，正文约 22 分钟。用 frontend-slides 技能的规范生成，视觉风格沿用十月的新马演示稿。

## 怎么打开、怎么讲

1. 用 Chrome 打开 `HogentX-Investor-Update-202611.html`。这是单个文件，图片已内嵌，拷到任何电脑都能用。字体从 Google Fonts 加载，没有网络时会换成系统中文字体，版式不变。
2. 翻页：← → 键、空格、鼠标滚轮，触屏可左右滑动。按 F 全屏。网址后面加 `#9` 可以直接跳到第 9 页。
3. **N**：打开或关闭讲稿面板。面板在屏幕右侧，投屏时观众也看得到，正式讲的时候建议关掉，用手机看 `speaker-notes.md`。
4. **E**：进入编辑模式，直接点文字修改。按 **Ctrl/⌘ + S** 把改好的版本下载成新的 HTML 文件。

## 文件

```
investor-202611/
  HogentX-Investor-Update-202611.html   演示稿（单文件，由 tools/build.py 生成）
  speaker-notes.md                      讲稿、时间分配、可能被追问的问题
  src/slides.html                       幻灯片正文（改内容改这里）
  src/style.css                         样式（改配色和字号改这里）
  src/script.js, src/controls.html      翻页、讲稿面板、行内编辑
  assets/                               截图、设计稿、门店照片、品牌素材
  tools/build.py                        拼装成单文件并生成讲稿
  tools/check.js                        逐页截图并检查溢出（需要 Playwright）
```

改了 `src/` 之后重新生成：

```bash
python3 tools/build.py
```

## 数据口径

- 住小叮：30 家已开业（20 家直营、10 家加盟），含签约与筹建共 54 家，不到 4,000 间房。团结湖店的账为取整数字，佣金为估算。
- 6 项日常任务用时为每周合计，口径是一位店长管两家店，内部业务反馈。
- 房态巡检数字取自 2026-11-12 团结湖店的一次巡检（1,890 条平台记录，498 条有房却关了房）。
- 收入提升仍在测试，页面上只写“测试中”。
- 外部数据的出处在附录 C。标“厂商自报”的未经第三方核验；标“拟”的是计划。
- `assets/shot-*.jpg` 裁自 2026-11-12 的产品截图；`design-*.jpg` 是设计稿，示例酒店为虚构。
