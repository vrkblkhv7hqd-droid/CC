## 品牌片：一条线，一镜到底

标志由三座斜顶塔楼和一条对角连线组成。片子把塔楼当作酒店，把连线当作智能体：
这条线在第 5 秒击穿夜景后就再没离开过画面，镜头沿着它一路前进，最后它收束成标志里的那一笔。

| 时间 | 小节 | 内容 |
| --- | --- | --- |
| 0–5 s | 1–2 | 夜景。塔楼是酒店，窗是房间，窗灯一盏盏熄灭 |
| 5–10 s | 3–4 | 光线击穿，三座塔楼充能成 H，城市的窗灯重新亮起 |
| 10–20 s | 5–8 | 白昼。沿线四站，四位数字员工 |
| 20–25 s | 9–10 | 480 → 174 分钟／周，−64%（住小叮 29 家自营酒店实验） |
| 25–30 s | 11–12 | 线收束为标志，字标逐字升起，口号落版 |

中英文共用同一套画面，文案和排版参数在 `film/lang.js`。英文版不是逐字翻译：
标题用句首大写、负字距、按词而不是按字母出现；长句拆成两到三行；界面标签、单位（min / week）、时间（8:00 AM）都换成英文读者熟悉的写法。

## 标志片：把标志拆开，再搭回去

| 时间 | 内容 |
| --- | --- |
| 0–5 s | 标志拆解：塔楼收回连线，连线收成一个点，再射出一条 26.8° 的线 |
| 5–10 s | 线上立起三座塔楼，屋顶 33.2°；两个角度相加正好 60° |
| 10–15 s | 镜头拉远，一个标志变成一片图案，琥珀色的波沿对角线扫过 |
| 15–20 s | 钻进一座塔楼，塔楼变成均衡器，高度由配乐的 13 个频段逐帧驱动；最后所有塔楼落到那条线上，三座留下，变回标志 |
| 20–25 s | 一天过去：太阳从塔楼后面划过，天色入夜，窗灯一间间亮起 |
| 25–30 s | 标志充能成白色，字标升起，落版 |

## 文件

```
film/lib.js          缓动、颜色、标志几何（屋顶斜率 0.6545、连线斜率 −0.5056）、文字动画
film/lang.js         品牌片的中英文文案与排版参数
film/engine.js       逐帧合成：子帧累积运动模糊（180° 快门）、辉光、暗角、胶片颗粒
film/world.js        品牌片：世界坐标、镜头时间线、四个色区
film/scene_*.js      品牌片各幕
film/logo_film.js    标志片（独立的一条片子）
film/audio_bands.js  标志片均衡器用的频段包络，由 audio.py 生成
film/brand_data.js   字标各字母的矢量路径（取自 deck/assets/brand/hogentx-wordmark.svg）
audio.py             配乐与音效合成；CUT=main 品牌片，CUT=logo 标志片
render.js            多进程渲染，输出无损分段
assemble.sh          拼接分段、编码、混入音轨
preview.js           出单帧或联系表
smooth.py            流畅度体检：逐帧变化量曲线，找出单帧突变和停顿
```

## 重新生成

需要 Node、Playwright（Chromium）、ffmpeg、Python（numpy、scipy）。Playwright 若装在全局目录，运行前先设置 `NODE_PATH` 指向它。

```bash
npm run setup
npm run audio:main && npm run audio:logo
npm run render:zh && npm run assemble:zh
npm run render:en && npm run assemble:en
npm run render:logo && npm run assemble:logo
```

每条片子 1800 帧，4 核约 13 分钟，无损分段约占 5 GB。只改了某一段时可以只重渲染那一段，
例如 `PAGE='index.html?lang=en' CHUNKS=chunks_en node render.js 0 330 4 30`，再重新 assemble。

## 流畅度体检

`python3 smooth.py 成片.mp4` 把成片缩小后逐帧比较，报告单帧突变和停顿。三条成片的结果：

- 品牌片（中、英）：没有停顿；唯一的单帧突变在 5.000 秒，是设计内的光线击穿闪光。
- 标志片：没有停顿；突变出现在 5.0、25.0 秒（两次冲击闪光）、7.5 秒（标志成形时的辉光）、14.9 秒（钻入塔楼的白场）、16.9 秒（均衡器跟着拍手声跳起），都是设计内的。

## 数据口径

品牌片中的数字全部取自演示稿第 7 页：实验范围为自有品牌「住小叮」29 家酒店（中国）；
计量口径是一位经理管理 2 家酒店时，6 项任务每周的合计用时；来源为内部业务反馈。片中同屏标注了这段说明。
