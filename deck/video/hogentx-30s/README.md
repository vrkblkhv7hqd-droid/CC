# HogentX 30 秒品牌动态短片

1920×1080 · 60 fps · 30.00 秒 · H.264 + AAC。画面和配乐都由这里的代码生成，没有用任何外部素材或模板。

## 创意：一条线，一镜到底

标志由三座斜顶塔楼和一条对角连线组成。片子把塔楼当作酒店，把连线当作智能体：
这条线在第 5 秒击穿夜景后就再没离开过画面，镜头沿着它一路前进，最后它收束成标志里的那一笔。

| 时间 | 小节 | 内容 |
| --- | --- | --- |
| 0–5 s | 1–2 | 夜景。塔楼是酒店，窗是房间，窗灯一盏盏熄灭：「酒店的收入，每天都在漏掉一点。」 |
| 5–10 s | 3–4 | 光线击穿，三座塔楼充能成 H，城市的窗灯重新亮起：「懂经营的酒店 AI 数字员工」 |
| 10–20 s | 5–8 | 白昼。沿线四站，四位数字员工：收益经理、宾客关系专员、质检主管、总经理助理 |
| 20–25 s | 9–10 | 数据：6 项日常任务每周合计用时 480 → 174 分钟，−64%（住小叮 29 家自营酒店实验） |
| 25–30 s | 11–12 | 线收束为标志，字标逐字升起，口号落版 |

配乐 96 BPM，12 小节正好 30 秒；镜头甩动、点击、冲击都落在节拍上。

## 文件

```
film/lib.js          缓动、颜色、标志几何（屋顶斜率 0.6545、连线斜率 −0.5056）、文字动画
film/engine.js       逐帧合成：子帧累积运动模糊（180° 快门）、辉光、暗角、胶片颗粒
film/world.js        世界坐标、镜头时间线、四个色区与分界
film/scene_night.js  第一幕：夜景、击穿、H 成形
film/scene_roles.js  第二幕：四位数字员工
film/scene_end.js    第三、四幕：数据与标志落版
film/brand_data.js   字标各字母的矢量路径（取自 deck/assets/brand/hogentx-wordmark.svg）
audio.py             配乐与音效合成（numpy / scipy）
render.js            多进程渲染，输出无损分段
assemble.sh          拼接分段、编码、混入音轨
preview.js           出单帧或联系表，用于检查
```

## 重新生成

需要 Node、Playwright（Chromium）、ffmpeg、Python（numpy、scipy）。Playwright 若装在全局目录，运行前先设置 `NODE_PATH` 指向它。

```bash
npm run setup      # 安装字体
npm run audio      # 生成 bgm.wav
npm run render     # 渲染 1800 帧（4 核约 13 分钟，分段占用约 5 GB）
npm run assemble   # 输出 MP4
```

只改了某一段时，可以只重渲染那一段，例如 `node render.js 0 660 4 30`，再 `npm run assemble`。

## 数据口径

片中数字全部取自演示稿第 7 页：实验范围为自有品牌「住小叮」29 家酒店（中国）；
计量口径是一位经理管理 2 家酒店时，6 项任务每周的合计用时；来源为内部业务反馈。片中同屏标注了这段说明。
